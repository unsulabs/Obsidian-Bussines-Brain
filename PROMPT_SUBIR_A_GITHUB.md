# Para Codex — preparar publicación del producto

Quiero preparar este producto para el repositorio y visibilidad que indicaré. Verifica archivos, licencia MIT y ausencia de datos empresariales reales, secretos, rutas personales e historial privado. Conserva las carpetas ocultas del producto.

Ejecuta la suite y una instalación sintética aislada. Revisa los archivos y el historial exactos que se subirían. No uses una bóveda como raíz del repositorio. Sólo configura un remoto con el nombre/URL y visibilidad proporcionados. Publica únicamente con autorización expresa; no cambies visibilidad por inferencia.

Las instancias privadas nunca forman parte de la publicación. No instales plugins ni accedas a datos reales durante este flujo.
