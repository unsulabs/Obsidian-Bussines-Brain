# Prioridades de mejora

Consulta [la hoja de ruta vigente](HOJA_DE_RUTA.md). La edición pública no distribuye estados de ramas ni expedientes de instancias privadas.

Mantén separación de fuentes, estados comerciales y aprobación editorial. Las pruebas de instalación, GUI y fidelidad semántica requieren evidencias distintas. Cada cambio de una instancia necesita autorización, detección de concurrencia y respaldo apropiados.
