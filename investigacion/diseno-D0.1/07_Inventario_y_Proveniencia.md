# Inventario y procedencia del producto

Los componentes publicados tienen funciones distintas: investigación, contrato, runtime y ejemplos sintéticos. Ninguno demuestra por sí solo aceptación empresarial.

| Componente | Ruta | Alcance |
|---|---|---|
| Metodología y prompts | `metodologia/vNext-1.0R/` | Fuentes, criterio experto, clases D/X y revisión |
| Contrato de intercambio | `contratos/vNext-0.9/` | Identidad, estados y validación estructural |
| Runtime y pruebas | `scripts/`, `tests/` | Operaciones técnicas reproducibles |
| Escenarios inventados | `ejemplos/` | Pruebas de aislamiento y recuperación |
| Análisis de tutoriales públicos | `investigacion/videos-2026-10/` | Hallazgos con enlaces; no transcripciones completas |

## Integridad de distribución

El exportador genera `PRODUCT_MANIFEST.json` dentro de cada ZIP con hashes recalculados y el commit público exportado. No se incluyen paquetes originales privados ni se atribuye a esta edición evidencia de otras instalaciones. Las referencias de terceros conservan sus derechos y no certifican capacidades instaladas.
